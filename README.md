# Tesis App Monorepo

Este proyecto contiene el backend en Spring Boot y el frontend en React.

- **backend/** – Microservicios implementados con Spring Boot
- **frontend/** – Aplicación web con React y Vite
- **config-repo/** – Ejemplo de repositorio de configuración

Consulta `backend/README.md` y `frontend/README.md` para instrucciones detalladas de instalación y ejecución.
